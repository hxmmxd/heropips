Cost Optimization & Caching Strategy
💡
LLM token management is critical. DeepSeek-R1 is highly cost-efficient on Groq/NIM at $0.59/M tokens. By enforcing system prompt caching and limiting active chat context depth, we ensure token consumption stays strictly within the projected $265/mo budget.
📡
Market data is heavily cached. Twelve Data Grow plan ($49/mo) has no daily limit but has rate limits. Enforcing 60-second server-side caching of OHLCV candles prevents redundant API requests and ensures we scale smoothly without needing expensive custom plans.
🖥️
VPS resource utilization is maximized. Unlike serverless architectures which have execution limits and cold starts, Utho VPS instances run persistent Node servers, scheduled cron syncs, and our custom MT5 Wine/Docker bridge with zero overhead.

Custom MT5 Farm & LLM Architecture Notes

📌 Building the Custom MT5 Farm & LLM Choice

  • Why not MetaAPI? MetaAPI's $5.00/month per active broker account scales poorly. At 1,000 users, Option A (MetaAPI) costs **$5,000 / month** in connection fees, whereas Option B (our own VPS MT5 farm) costs just **$248 / month** (savings of over **$4,700 every single month**).
  • Development Cost & Payback: Building the custom farm has a one-time development and setup fee of **$3,500 USD**. Since we save $4,728.96 every single month on MetaAPI fees, the development cost is fully recovered in the first **22 days** of hitting 1,000 users.
  • Reasoning LLM (DeepSeek-R1): To ensure highly accurate trading logic and indicator math, we use **DeepSeek-R1 (Distill Llama 70B)** on Groq. The cost is **$265/mo** at 1,000 users due to the higher token output (~1,500 tokens/req including reasoning steps). If upgrading to the full **DeepSeek-R1 671B** model, the cost increases to **$540/mo**.
  • Hardware Layout: We deploy Wine (Windows emulator for Linux) + MetaTrader 5 inside lightweight Docker containers. Each account takes ~120 MB RAM. We run up to 250 accounts per Utho Memory Optimized 3 VPS instance (32 GB RAM). Four servers cover 1,000 accounts.
  • Database Scaling: Supabase Pro ($25/mo) handles up to 8 GB of data, which easily stores active broker keys, trades, signals, and course progression tables for 1,000 users.
