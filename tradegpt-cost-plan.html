Free Tier Strategy
💡
LLM cost is nearly zero at MVP scale. Groq's free tier allows 7,000 requests/day — enough for 700 users sending 10 messages each. The circuit-breaker failover to NVIDIA NIM adds a second free pool. LLM costs only become meaningful above 500 daily active users.
📡
Market data is aggressively cached. Twelve Data free plan provides 800 API calls/day. With 60-second server-side caching and parallel batch fetching, each signal generation uses ~5 real calls. 800 calls = ~160 signal analyses per day — sufficient for early users at zero cost.
🌙
Astro mode costs $0 at any scale. The astronomy-engine npm package runs all celestial calculations (lunar phases, Mercury retrograde, eclipse detection) as pure JavaScript — no external API, no per-call cost, no rate limits.
⚡
Vercel free tier can handle MVP traffic. The Hobby plan supports 100 GB/month bandwidth, unlimited deployments, and 6,000 build minutes. Only upgrade to Pro ($20/mo) when you need custom domains on multiple projects or commercial usage rights.
Cost Optimization Roadmap

📌 As You Scale — Key Cost Decisions

  • LLM: Add 3–5 NVIDIA NIM API keys (they each get 40 free req/day on trial) and configure round-robin rotation in llmRouter.ts to extend the free window.
  • Database: Supabase free plan hits 500 MB at ~100k signal rows. Migrate to Pro ($25/mo) early — Supabase Pro is much cheaper than alternatives like PlanetScale or Neon.
  • Market Data: At 500+ users, switch Twelve Data to the Basic plan ($8/mo = 5k calls/day). Above 5k active users, consider Polygon.io or self-hosting a free data provider like yfinance with a scheduled job.
  • MetaAPI: Each user who connects a live broker account costs roughly $0.10/mo on the per-account billing model. Pre-charge users via the subscription or absorb as COGS.
  • Self-host option: At scale (1000+ users), moving the database to a $12/mo DigitalOcean PostgreSQL droplet and using Railway for hosting can cut costs by 60% vs. managed Vercel + Supabase Pro.
  • CDN: All chart assets, SVG icons, and static JS are already cached by Vercel's CDN edge. No additional CDN cost unless you add user-uploaded media (e.g., course videos).
